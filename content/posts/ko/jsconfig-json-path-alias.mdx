## 1. vscode에서 자동 import
1.1. `command` + `.` 단축어 실행 시 자동 import가 안됨
![VS Code에서 useState에 빨간 밑줄이 그려진 상태로 Quick Fix 메뉴를 열었으나 no-undef 규칙 비활성화와 Move to file 항목만 있고 import 추가 항목이 없는 화면](/images/jsconfig-json-path-alias/01.png)

1.2. jsconfig.json 에서 `"checkJs" : "true"` 설정 추가
![jsconfig.json 파일 내용. compilerOptions에 module CommonJS, target ES6, jsx react-jsx, checkJs true 가 설정되어 있다](/images/jsconfig-json-path-alias/02.png)

1.3. Quick Fix 목록에 import 가능하게끔 추가 됨
![checkJs를 켠 뒤 같은 위치에서 Quick Fix를 열었을 때 Update import from "react" 와 Add import from "react" 항목이 나타난 화면](/images/jsconfig-json-path-alias/03.png)


## 2. js 파일임에도 타입 검사를 하라고 나옴
2.1. 해당 문제
![js 파일인데도 event.target.focus 에 Property 'focus' does not exist on type 'string'. ts(2339) 타입 에러가 표시된 VS Code 화면](/images/jsconfig-json-path-alias/04.png)

2.2. 해결 방안은 `"checkJs" : "true"` 옵션을 삭제해야 됨

## 3. yarn start 명령어 실행 시 node: internal/modules/cjs/loader:1456 Throw err
3.1. 해당 문제
![yarn start 실행이 실패한 터미널 출력. SyntaxError: jsconfig.json: Expected double-quoted property name in JSON at position 100 과 react-scripts의 스택 트레이스가 보인다](/images/jsconfig-json-path-alias/05.png)

  "compilerOptions": {
