## GitLab Personal Access Token 발급

- GitLab > User Settings > **Access Tokens**
- Token name: `jenkins-token`
- Expiration date
- Select scopes
    - api
    - read_user
    - read_repository

![GitLab의 Personal access tokens 생성 폼. Token name은 jenkins-token이고 scope로 api, read_user, read_repository를 선택한 상태](/images/jenkins-gitlab-integration/01.png)


## Jenkins에 GitLab Credentials 추가

- Jenkins > **Jenkins 관리 > System**
- Kind
- Secret: `${GitLab Token}`
- ID: GitLabToken

![Jenkins 관리 > System의 GitLab 섹션에서 Add Credentials 모달을 열어 Kind를 GitLab API token으로, ID를 gitLabToken으로 지정한 화면. 토큰 값은 마스킹되고 모달 뒤 host URL은 블러 처리되어 있다](/images/jenkins-gitlab-integration/02.png)


## Jenkins에 GitLab Credentials 추가

> 추후 Jenkins job 생성 시 git repo 인증에 사용
>
- Jenkins > **Jenkins 관리 > Credentials > System > Global credentials**
- Kind: Username with password
- Secret: `${GitLab Token}`
- ID: gitlab-user-token

![Jenkins Global credentials의 New credentials 폼. Kind는 Username with password, ID는 gitlab-user-token이고 비밀번호는 마스킹되어 있다](/images/jenkins-gitlab-integration/03.png)
