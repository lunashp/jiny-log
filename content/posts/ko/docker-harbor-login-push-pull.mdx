description: "HTTP로 띄운 Harbor에 docker login을 하면 Docker가 HTTPS로 접속을 시도해 실패한다. daemon.json의 insecure-registries에 레지스트리를 등록해 해결하는 방법과, 이미지 태그·push·pull 경로 규칙을 정리한다."
summary: "Docker 클라이언트는 레지스트리에 기본적으로 HTTPS로 붙는다. Harbor를 HTTP(포트 5000)로 띄웠다면 /etc/docker/daemon.json의 insecure-registries에 해당 호스트:포트를 넣고 dockerd를 재시작해야 로그인이 된다. push할 이미지는 HOST:PORT/PROJECT/IMAGE:TAG 형식으로 태그해야 하며, 이 경로가 Harbor의 프로젝트 구조와 1:1로 맞아야 한다."

## **Docker에서 Harbor에 로그인**

```bash
docker login <HARBOR_HOST>:<PORT>
```

## **Harbor에 설정한 계정의 ID/PW 입력**

 http: server gave HTTP response to HTTPS client

## 로그인 시 아래와 같은 에러가 난다면

```bash
Error response from daemon: Get "https://VM_HOST:5000/v2/": http: server gave HTTP response to HTTPS client
ubuntu@luna-vm:~/luna-workspace/harbor$ docker login VM_HOST:5000
Username: admin

i Info → A Personal Access Token (PAT) can be used instead.
         To create a PAT, visit https://app.docker.com/settings
         
         
Password: 
Error response from daemon: Get "https://VM_HOST:5000/v2/": http: server gave HTTP response to HTTPS client
```

## **`/etc/docker/daemon.json` 수정**

```bash
sudo vim /etc/docker/daemon.json
```

아래 내용을 추가 (또는 수정)

```json
{
  "insecure-registries": ["VM_HOST:5000"]
}
```

## **Docker 데몬 재시작**

```bash
sudo systemctl restart docker
```

## **다시 로그인 시도**

```bash
sudo docker login VM_HOST:5000
```


## **image Push / Pull**

### image push

> Harbor는 특정 경로를 따라 이미지를 저장함
>

#### **Docker 이미지에 태그 설정**

```bash
<HARBOR_HOST>:<PORT>/<PROJECT_NAME>/<IMAGE_NAME>:<TAG>

sudo docker tag backend-base:jdk21 VM_HOST:5000/devops-project/backend-base:jdk21

sudo docker tag frontend-base:node20 VM_HOST:5000/devops-project/frontend-base:node20
```

- Harbor 주소: `VM_HOST:5000`
- 프로젝트 이름: `devops-project`
- Docker 이미지 이름: `backend-base`, `frontend-base`
- 태그: `jdk21`, `node20`

#### **Docker 이미지 Push**

```bash
sudo docker push VM_HOST:5000/devops-project/backend-base:jdk21

sudo docker push VM_HOST:5000/devops-project/frontend-base:node20
```

**성공하면 Harbor UI에서 확인 가능**

#### **image Pull test**

```bash
<HARBOR_HOST>:<PORT>/<PROJECT_NAME>/<IMAGE_NAME>:<TAG>

sudo docker pull VM_HOST:5000/devops-project/backend-base:jdk21
```
