## 이 글의 목적

`draft: true` 필터링이 실제로 동작하는지 확인하기 위한 글이다.

프로덕션 빌드(`pnpm build`)에서는 이 글의 라우트 자체가 생성되지 않아야 하고, 개발 서버(`pnpm dev`)에서는 보여야 한다.

## 확인 방법

```bash
pnpm build
# 출력된 라우트 목록에 /ko/posts/draft-example 이 없어야 한다
```

유닛 테스트로도 고정되어 있다 (`src/lib/content/queries.test.ts`).
